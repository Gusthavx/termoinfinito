Dueto e Quarteto

Nos modos com várias palavras, cada tentativa é testada em todos os quadros ao mesmo tempo. O desafio é decidir quando explorar letras novas e quando fechar um quadro.

Regras

  • Dueto: duas palavras secretas, 7 tentativas.
  • Quarteto: quatro palavras secretas, 9 tentativas.
  • Cada palpite aparece em todos os quadros que ainda não foram resolvidos, com as cores calculadas para cada um.
  • Quando você acerta uma palavra, aquele quadro para de receber tentativas.
  • Você vence se acertar todas as palavras dentro do limite.

O teclado dividido

No Dueto, cada tecla é dividida ao meio: a metade esquerda mostra a cor da letra no primeiro quadro e a direita, no segundo. No Quarteto, a tecla vira quatro quadradinhos, um para cada quadro, na mesma ordem da tela. Uma tecla apagada significa que a letra não serve em nenhum quadro que falta resolver.

Estratégia: primeiro cobrir, depois resolver

Com várias palavras, uma letra testada rende informação em todos os quadros de uma vez. Por isso, as primeiras tentativas valem mais quando cobrem muitas letras diferentes:

  1. Abertura fixa. Duas palavras sem letras em comum, como SÉRIO e CALMA (calculamos em Dicas), cobrem nove letras, entre elas as mais frequentes.
  2. Resolva o quadro mais adiantado. Se um quadro está com quatro verdes, feche-o: cada tentativa ali também gera cores nos outros quadros.
  3. Escolha palpites que sirvam a mais de um quadro. Entre duas candidatas para o quadro 1, prefira a que testa letras ainda abertas nos quadros 2 a 4.
  4. Guarde margem. No Quarteto, chegue à 6ª tentativa com pelo menos dois quadros quase resolvidos. Sobram três tentativas para fechar os quatro.

Erros típicos

  • Ficar preso tentando fechar um quadro difícil e esquecer que os outros também precisam de tentativas.
  • Ignorar as cores de um quadro já resolvido: a partir do acerto ele não conta mais, então olhe o teclado só para os quadros abertos.
  • Repetir uma letra cinza "porque estava verde no outro quadro". Cada quadro tem a própria resposta.

Comece pelo Dueto

Se o Quarteto parece muita coisa, jogue algumas partidas de Dueto antes. A lógica é a mesma, com metade da informação para acompanhar.
